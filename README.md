# GeoLang.github.io

The public website and developer documentation for the GeoLang open geospatial
platform.

- [Project website](https://geolang.github.io/)
- [Developer documentation](https://geolang.github.io/docs/)
- [Source repositories](https://github.com/GeoLang)

The site is static HTML. Open `index.html` for the project page or
`docs/index.html` for the developer guide.
