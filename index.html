Platform Capabilities

23 repositories, 21 of them in Rust.

Natural Language Analysis

The agent turns your question into calls to 41 geospatial tools. Sibyl runs the agent loop and keeps each session's history in SQLite, and geolang serves and runs the tools.

The agent drives the viewer (AG-UI)

Every run carries the map state and the viewer's own action catalogue, so the agent runs the panels you would have clicked. Its answers come back as a UI spec the viewer renders: a map of named layers with colours or a shading column, an output image, or a table.

Enterprise Geodatabase

Git-like versioning for spatial data. Branch, commit, merge, diff. Role-based access, OIDC SSO. PostGIS-powered. Every mutation that answers 2xx writes an audit row, readable at /api/v1/audit by an instance admin.

Live Collaboration

Agora holds a shared map as one document of layers, annotations, bookmarks and comments, orders every edit and fans it out to everyone viewing. Per-document members, share links and comment mentions. Taking back your own last edit is the viewer's, not the server's.

ArcGIS Migration

Verne inventories a KML/KMZ, Esri file geodatabase, or hosted ArcGIS feature service and reports, item by item, what GeoLang holds faithfully, approximates, or has no home for. It then extracts features, semantics, and attachments and loads them into the geodatabase. The source is never written to.

Geoprocessing

Ptolemy runs clip, intersect, difference, dissolve, spatial join, voronoi, convex hull, centroid, nearest neighbour, distance matrix, contour, merge, split, simplify and densify on a branch, and buffer as an analytics route. Geodukt's REST service exposes buffer, centroid, clip, dissolve, and simplify as GP-as-a-service.

3D Tiles

TileTopia tiles point clouds, meshes (glTF, glb, OBJ, FBX, CityGML) and IFC with its own tiler, and GeoJSON, GeoPackage and KML through mago-3d-tiler. Quantized-mesh terrain from a DEM or a prebuilt bundle. IFC tiles carry each element's GlobalId, so a picked tile feature reads its id back. DAE is the one format neither tiler takes.

Routing & Network Analysis

Shortest path, isochrones, network graph analytics (OD matrix, centrality, connected components). OpenStreetMap-powered.

Field Collection

Collecta is the server: XLSForm import, 21 field types, SQLite persistence, an offline sync queue in the CLI client, and media attachments. ODK Collect fills the forms in over an OpenRosa layer, and publishing a form writes its submissions into a Ptolemy dataset. A field app of our own is on the roadmap.

Mobile SDK

Rust-native mobile SDK, Android only. The Android library fetches tiles over HTTP and draws on Canvas, including MVT. There is no GPU backend and no iOS binding.

EO & Remote Sensing

COG streaming, EO time-series analysis (composites, trend fitting, change detection, anomaly scores, phenology). Panoptes segments imagery through ONNX Runtime. Building weights are published as a release asset. Roads, vegetation and landcover have none and run a threshold heuristic instead.

Portal & Dashboards

Content catalog for maps, layers, and datasets. Configurable dashboards with map, chart, indicator, gauge, list, and rich-text widgets.

WASM Computational Geometry

Topoi compiles to WASM: convex hull, Delaunay, buffer, clip, simplify, and spatial predicates, all exported to the browser.

Geostatistics

Empirical variograms with a fitted spherical model, ordinary kriging onto a grid, Moran's I spatial autocorrelation, Getis-Ord Gi* hot-spot scores.
