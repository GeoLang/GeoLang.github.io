Platform Capabilities

20 modules, 18 of them Rust-native. One unified platform.

🤖

Natural Language Analysis

GeoLang AI agent translates your questions into spatial operations. The sibyl agent loop drives 39 geospatial tools and keeps each session's history in SQLite.

🎨

Adaptive UI (A2UI)

Every response generates a custom interface — maps, charts, tables, forms — tailored to your specific question. No static dashboards.

🗄️

Enterprise Geodatabase

Git-like versioning for spatial data. Branch, commit, merge, diff. Role-based access, OIDC SSO. PostGIS-powered. Audit log writes have no callers.

🤝

Live Collaboration

Agora holds a shared map as one document — layers, annotations, bookmarks, comments — orders every edit and fans it out to everyone viewing. Per-document members, share links, comment mentions, per-user undo.

🧳

ArcGIS Migration

Verne inventories a KML/KMZ, Esri file geodatabase, or hosted ArcGIS feature service and reports, item by item, what GeoLang holds faithfully, approximates, or has no home for. It then extracts features, semantics, and attachments and loads them into the geodatabase. The source is never written to.

🔬

Geoprocessing

Buffer, clip, intersect, dissolve, voronoi, spatial join, nearest neighbor, and distance matrix across Topoi, Geodukt, and Itinera. Geodukt's REST service exposes buffer, centroid, clip, dissolve, and simplify as GP-as-a-service.

🌐

3D Tiles

Point-cloud 3D Tiles and quantized-mesh terrain from TileTopia. Mesh, vector and BIM readers exist. The tiling job queue does not call them.

🚗

Routing & Network Analysis

Shortest path, isochrones, network graph analytics (OD matrix, centrality, connected components). OpenStreetMap-powered.

📡

Field Collection

XLSForm import and 20+ field types with local SQLite persistence, an offline sync queue, and media attachments. A native mobile client is on the roadmap.

📱

Mobile SDK

Rust-native mobile SDK. The Android library fetches tiles over HTTP and draws on Canvas, including MVT. Metal/Vulkan backends are on the roadmap.

🛰️

EO & Remote Sensing

COG streaming, EO time-series analysis (composites, trend fitting, change detection, anomaly scores, phenology). Panoptes segments imagery through ONNX Runtime, falling back to a threshold heuristic until model weights ship.

📊

Portal & Dashboards

Content catalog for maps, layers, and datasets. Configurable real-time dashboards with map, chart, indicator, gauge, and list widgets.

📐

WASM Computational Geometry

Topoi WASM SDK — convex hull, Delaunay, buffer, clip, simplify, and spatial predicates running in the browser at near-native speed.

📈

Geostatistics

Variogram modeling (spherical, exponential, gaussian), Ordinary Kriging, Moran's I spatial autocorrelation, Getis-Ord Gi* hot-spot analysis.
